## Re-run it yourself

```
git clone https://github.com/Kylne700/mezo-agent-toolkit
cd mezo-agent-toolkit
npm ci
npm run w2:prove
```

`npm run w2:prove` needs no key and sends nothing. It reads each receipt from the public RPC (`https://rpc.test.mezo.org`), checks the ledger against the chain (sender, target, nonce, selector, gas, amounts), and reads the state the leg claims at the receipt's block and at the block before it. It prints one PASS, FAIL or SKIP line per leg. SKIP means the RPC no longer serves state at that old block; the receipt checks of that leg still ran and passed. The exit code is 1 on any FAIL. The last line should read:

```
result: 14 PASS, 0 FAIL, 0 SKIP
```

Our saved run is [claim1-w2-prove.txt](evidence/w2/claim1-w2-prove.txt) (head block 16578215). The gas per leg and the count of payers to the demo payee come from a second read-only script, `npx tsx scripts/w2-economics.ts`; its saved run is [b-economics.txt](evidence/w2/b-economics.txt).

- Outside use. Every transaction is ours, and so is every payment to the demo payee (49 of 49, counted in [docs/BUSINESS.md](docs/BUSINESS.md#own-traffic-and-outside-traffic)).
- Mainnet behaviour, or what fees and gas cost outside testnet.
- The paid plan call ran on a local server with our own wallet as payee, so it shows the settlement, not a sale. A wallet with no BTC at all was not tried.
